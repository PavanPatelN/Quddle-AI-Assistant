# 🚀 Quddle.ai Assistant

**Quddle.ai Assistant** is your smart AI chatbot companion for the Quddle.ai platform! It delivers instant, human-like answers to questions about features, pricing, and plans — making your website interactive and user-friendly.

---

## ✨ Features
- **Instant Answers:** Get quick responses about Quddle.ai anytime.  
- **Human-like Conversations:** Powered by OpenAI GPT for natural language understanding.  
- **Interactive Widget:** Chat directly on the website without leaving the page.  
- **24/7 Support:** Always available to help visitors.  
- **Easy Integration:** Modern Node.js backend + lightweight frontend widget.

---

## 🛠 Technology Stack
- **Backend:** Node.js, Express, Node-Fetch, dotenv, CORS, Body-Parser  
- **Frontend:** HTML, CSS, JavaScript  
- **AI Engine:** OpenAI GPT API
